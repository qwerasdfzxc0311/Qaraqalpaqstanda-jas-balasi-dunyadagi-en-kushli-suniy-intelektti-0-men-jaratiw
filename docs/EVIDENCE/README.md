# Evidence and Source Register

## Claim handling

Every material factual claim should be represented with:

- atomic claim text and scope;
- source title, author/organization, publisher/venue, and date/version;
- stable identifier or URL (DOI, official page, arXiv, standards catalog, repository);
- source type: peer-reviewed paper, preprint, standard, official documentation, dataset, or secondary commentary;
- exact claim supported and relevant location;
- review depth: metadata, abstract, full text, data/code, or independent replication;
- method, sample, assumptions, limitations, and counterevidence;
- access date and applicable license/usage terms;
- confidence rationale and review status.

## Evidence rules

1. Do not label a preprint peer-reviewed unless verified.
2. Abstract-only inspection is not a full-text review.
3. A benchmark result is specific to its benchmark, model, setup, and metric; it is not automatically a production prevalence estimate.
4. Correlation does not establish causation.
5. Repeated claims do not become independent evidence.
6. Preserve retractions, corrections, and superseded versions.
7. Distinguish empirical findings, author interpretations, and project hypotheses.
8. Cite original sources wherever possible and avoid reproducing material beyond its license.

## Current state

The project has ongoing literature reviews in memory architecture, continual learning, agent security, and biologically inspired mechanisms. The complete source-by-source register and detailed reviews remain in the canonical research workspace and must be reviewed for publication rights and attribution before being copied into this repository.

## Release gate

No third-party text, figure, dataset, or code is included in this initial documentation package. External references may be linked for discovery, but link presence does not imply endorsement or license to reproduce.
